# Retro Alien Shooter - Final (Buttoned K1-B)

This Next.js project includes an in-screen arcade red PLAY / PLAY AGAIN button (K1-B - bottom-center in the monitor screen).
Place your monitor image at public/monitor.png (already provided).

Run locally:
1. npm install
2. npm run dev
3. Open http://localhost:3000

Controls:
- Arrow Left / Right: move
- Space: shoot (does not start the game)
- Click PLAY to start, PLAY AGAIN to restart

Deploy to Vercel: push to GitHub and import as a Next.js project.
